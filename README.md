# John Ravonni Basilio — Portfolio Website

A responsive static portfolio starter built with HTML, CSS, and JavaScript.

## Included
- Responsive desktop, tablet, and mobile layout
- Home, About, Skills, Experience, Projects, Education, CV, Contact
- Search and category filter for project cards
- Project detail dialogs
- Dark/light mode saved in browser local storage
- Contact form that can open an email client after configuration
- Basic SEO and social sharing metadata
- Accessible labels, keyboard-friendly controls, reduced-motion support

## Before submitting or publishing
1. Review every section and correct any details that do not reflect your actual background.
2. Add a professional photo if you want one. The current initials graphic is a placeholder.
3. Update education, experience, skill levels, project roles, project years, and project status.
4. Add only real screenshots and links to working demos/source code.
5. Export your latest CV as `cv.pdf` and place it beside `index.html`.
6. In `script.js`, replace `YOUR_EMAIL_HERE` with the email address you want to publish.
7. Add your actual email, phone (optional), GitHub, LinkedIn, and credentials in `index.html`. Do not publish sensitive ID numbers or private documents.
8. Test the contact form and all links after deployment. The default form uses `mailto:`; it does not store messages on a server. For direct submissions, connect a trusted form/backend service and protect it from spam.
9. Update canonical URL and sitemap if you deploy to a custom domain.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository named `ravonni-portfolio` (or another name).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder. Upload `cv.pdf` only after you have added your own CV.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The public URL normally follows `https://YOUR-USERNAME.github.io/ravonni-portfolio/`.
6. Open the URL on a phone and a computer. Test navigation, project search, dark mode, CV links, and contact form.
7. If you later add a custom domain, configure DNS using GitHub's current instructions and enable HTTPS in Pages settings.

## Important
This package is a website starter and is not yet publicly hosted. A public URL requires deployment from an account you control. Do not claim that the website is live until you have completed deployment and tested it.
